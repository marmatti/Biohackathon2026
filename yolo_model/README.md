# YOLO Model Workspace

This folder contains data, notebooks, model weights, and outputs for YOLO-based filament segmentation experiments.

## Contents Overview

Top-level files:

- `training.ipynb`: Main notebook for model training.
- `predict.ipynb`: Main notebook for inference/prediction.
- `yolo26n.pt`: Model weights/checkpoint file.
- `yolov8s-seg.pt`: Segmentation model weights/checkpoint file.

Top-level folders:

- `for_training/`: Training-ready dataset split for YOLO.
- `test_data/`: Input datasets used for testing/inference.
- `results/`: Prediction outputs and exported result sets.
- `runs/`: YOLO run artifacts (training logs, checkpoints, validation outputs).

## Folder Details

### for_training/

Training dataset in YOLO format.

- `data.yaml`: Dataset config used by training.
- `images/train`, `images/val`, `images/test`: Image splits.
- `labels/train`, `labels/val`, `labels/test`: Label splits.

### test_data/

Inference/test input datasets, including crop-based and user/background-processed sets.

### results/

Prediction output folders generated by inference runs.

### runs/

Auto-generated YOLO run artifacts (for example under segmentation runs), including logs, metrics, and checkpoints.

## Typical Workflow

1. Prepare source data in `data/`.
2. Build YOLO train/val/test splits in `for_training/`.
3. Train models in `training.ipynb`.
4. Run inference in `predict.ipynb`.
5. Check generated outputs in `results/`, `runs/`, or `yolo_results/`.


## Notes

- Large model weights and generated outputs can quickly make the repository heavy.
- Keep reproducible inputs/configs in Git; keep temporary artifacts outside Git when possible.
